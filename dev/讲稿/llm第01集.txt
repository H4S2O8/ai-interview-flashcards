llm第01集　什么是大语言模型？和传统 NLP 模型有什么区别？
============================================================

仁菜：欢迎回来。我是仁菜——转正了，工牌换成白的了。今天甜点我没买着，加班到店都关门了……
桑多涅：坐。烤红薯——路口那个摊，还热着。
仁菜：……你带的？
桑多涅：别多想。这季……我有事求你。
仁菜：诶？！
桑多涅：你们那台机器上的真实负载数据，我要。我手上有个问题卡了很久——缺一个真生产环境验。
仁菜：所以这季不是你考我，是我们交换？
桑多涅：名义上还是学费。……先说你的 P0 是什么。
仁菜：公司要自建大模型能力。导师给了我一句话和一个数字——话是「把这条线吃透」，数字是 GPU 预算。
桑多涅：多少呢。
仁菜：够跑一轮完整训练加若干次微调——烧完就停，不追加。
桑多涅：那这季每一集你都要报一次余额。这个板块什么都贵——不盯着钱，你会做出一堆看起来很美的选择。
仁菜：明白。那第一课——导师今天问我，什么是大语言模型。
桑多涅：你怎么答的。
仁菜：我说就是 ChatGPT 那种嘛，参数特别多、能聊天的。
桑多涅：Siri 也能聊天啊。它是大语言模型吗。
仁菜：……不是。
桑多涅：「参数多」——多到什么量级才算大。为什么参数多了就能聊天。
仁菜：……我改口说，参数到亿级以上、训练数据特别多、能做各种 NLP 任务的模型。
桑多涅：你说的还是结果，不是本质。BERT 也有几亿参数呢——那 BERT 是不是大语言模型。
仁菜：呃……
桑多涅：传统 NLP 是先分词、再词性标注、再命名实体识别，最后做下游任务——LLM 是怎么做的。
仁菜：LLM 不分这些步骤吧，是端到端的？
桑多涅：「端到端」二零一五年就在说了。那时候的 LSTM 是端到端的，BERT 接个分类头也是端到端的——你这个回答放十年前都不算新。
仁菜：……那我到底该说什么。
桑多涅：从它之前的世界说起——传统 NLP 怎么干活的。
仁菜：流水线吧？一个任务拆成好几步，每步一个专门的模型。
桑多涅：那为什么要拆。
仁菜：因为当时的小模型能力有限嘛。复杂问题必须拆成简单的子问题，每个子问题单独训一个模型才搞得定。
桑多涅：举个例子——就用你熟的客服。
仁菜：第一步分词，把「我想退货」拆成「我、想、退货」；第二步词性标注，标出「我」是代词、「退货」是动词；第三步命名实体识别，找商品名和订单号；第四步意图分类，判断是咨询还是投诉；第五步去知识库匹配预设答案。
桑多涅：光第一步就有一堆坑。中文和英文差在哪呢。
仁菜：中文没有空格天然分隔！比如「南京市长江大桥」——到底是「南京市、长江大桥」，还是「南京、市长、江大桥」？
桑多涅：这种歧义规则解决不了，得有专门的分词模型判断。而分词模型又依赖大量人工标注语料。遇到训练时没见过的新词呢。
仁菜：比如「奥利给」「绝绝子」这种？
桑多涅：它就懵了。这叫 OOV，未登录词。每一步都有自己的痛点、自己的模型、自己的标注规范——整条 pipeline 又长又脆。
仁菜：脆在哪？
桑多涅：前面错一步，后面全错。分词错了词性就错，词性错了实体识别就错，最后意图分类跟着错——错误会累积传导，而且没法事后补救。
仁菜：……那要是换个领域呢？比如从客服换到医疗问答。
桑多涅：所有模型基本重训。医疗的实体是药名、症状、检查项目，电商的实体是商品、订单、品牌——完全不是一回事。
仁菜：一个公司想做几个领域的应用，就得养几套模型团队？
桑多涅：任务越细分模型越多，模型越多标注越贵，标注越贵迁移越难——整个行业困在这个死循环里。这就是 LLM 出现之前的世界。
仁菜：那第一个突破口是什么呀？
桑多涅：二零一八年，Google 的 BERT——核心创新是预训练加微调，两阶段。
仁菜：预训练阶段它干什么呢？
桑多涅：在海量无标注文本上做两件事。第一是 MLM，掩码语言模型——随机遮掉句子里百分之十五的词，让模型根据上下文猜被遮的是什么。
仁菜：第二呢？
桑多涅：NSP，下一句预测——给两个句子，判断它们是不是连续的。这两个任务都不需要人工标注，纯靠原始文本，所以能用海量数据。
仁菜：海量是多少啊？
桑多涅：维基百科加图书数据，约三十三亿词。经过预训练，BERT 学到了通用的语言表示能力——说白了就是「看懂文字」。
仁菜：然后下游任务只要接一个小头，用少量标注微调一下就行了？
桑多涅：它把各项任务的 SOTA 刷了个遍，整个领域为之一振。……但它只走了一半。
仁菜：哪一半没走完？
桑多涅：它解决了「特征通用」——一个 BERT 可以服务多个下游任务。但没解决「任务统一」——不同任务还是要不同的微调副本。两个原因。
仁菜：第一个？
桑多涅：BERT 的输出是「表示」，不是「文本」——它吐的是每个 token 的向量。你要做分类，得接一个分类头；要做实体识别，得接序列标注头；要做问答，得接抽取式 QA 头。
仁菜：每种任务都要单独设计的头、单独标注的数据、单独训练的过程……
桑多涅：一个 BERT 在公司里用起来，可能派生出十几个微调副本，每个负责一件事。第二个原因呢——BERT 不擅长生成。
仁菜：为什么？
桑多涅：它的预训练目标 MLM 是填空题，每次只猜一个被遮的词，没学过怎么连续生成长文本。所以翻译、写作、对话这类活它几乎不做。
仁菜：那 BERT 是把「理解」做到了极致，「生成」是短板。
桑多涅：它证明了预训练加大规模无标注数据这条路是对的，但没把所有任务收归到同一个接口下。做完这一步的是 GPT 系列。
仁菜：怎么收的？
桑多涅：把所有 NLP 任务统一成一件事——预测下一个 token。
仁菜：……就这？
桑多涅：这个训练目标叫 CLM，因果语言模型。给一段文本，模型从左到右一个字一个字往后猜。训练数据是「我喜欢吃苹果」，它要学会：看到「我」预测「喜」，看到「我喜」预测「欢」，看到「我喜欢」预测「吃」。
仁菜：下一步的预测依赖上一步的输出——这就是自回归？
桑多涅：GPT、Claude、Qwen、DeepSeek，本质都是自回归加因果掩码的语言模型。
仁菜：可是这么简单的目标，怎么就能干所有任务？
桑多涅：你自己想。翻译怎么用它做。
仁菜：Prompt 写「把下面这句翻译成英文：我喜欢你」，然后让它接着往下预测——它就会输出 I like you！
桑多涅：分类。
仁菜：「下面这条评论是正面还是负面？『这家店太黑了』，答：」——它预测下一个 token 就是「负面」。
桑多涅：总结、写代码，同理。所有任务都被「Prompt 加续写」这个统一接口收编了。
仁菜：所以我不用为每个任务训不同的模型，只要在 Prompt 里换个说法……
桑多涅：一个模型切换到不同的工作模式。那为什么这个简单目标能学到这么多东西。两个杠杆。
仁菜：数据？
桑多涅：CLM 不需要任何人工标注，互联网上所有文本天然都是合格的训练数据。GPT-3 用了三千亿 token，第三代 Llama 用了十五万亿。
仁菜：BERT 当年是几十亿词……翻了几千倍。
桑多涅：第二个杠杆是模型规模。BERT 是三亿参数，GPT-3 一千七百五十亿。
仁菜：那 GPT-4 呢？我看网上都说万亿级——
桑多涅：停。官方没公开过。外界只能估计。面试里把「万亿级」当确定事实讲，遇到懂行的当场就穿。
仁菜：那该怎么说？
桑多涅：说模型规模、训练数据和算力一起放大之后，「预测下一个 token」这件事被推到了新的境界。稳，而且是真的。
仁菜：可我还是不懂——为什么光是猜下一个字，就能学会那么多东西？
桑多涅：因为要在不同上下文里都猜准，它就必须学到语法、事实和推理。你要预测「北京是中国的」下一个词，模型必须知道北京是首都。
仁菜：要预测「如果 x 等于二，那么 x 的平方等于」，它必须会算数。
桑多涅：要预测一段代码的下一行，它必须理解编程逻辑。所有这些能力，都是被这个看似简单的目标逼着学会的。
仁菜：……有点吓人。
桑多涅：还有个副产物更吓人。在 Prompt 里给它几个例子，它就能学会新任务模式，不更新任何参数。
仁菜：不训练也能学？
桑多涅：叫 In-Context Learning，上下文学习。GPT-3 之后业界才发现的，也是 Prompt 工程这门学科诞生的基础。
仁菜：那这些能力是一开始就有的吗？
桑多涅：不是。规模到了某个临界点才突然出现。这叫涌现能力。
仁菜：突然是有多突然？
桑多涅：Google 二零二二年测多步算术，要五步计算的应用题。八十亿参数以下的模型，准确率几乎是零。
仁菜：六百二十亿呢？
桑多涅：百分之五。到了五千四百亿的 PaLM——百分之六十。
仁菜：……中间没有过渡？
桑多涅：这里要留个心眼。有研究认为，一部分「突然出现」可能来自评测指标的离散性。
仁菜：什么意思？
桑多涅：exact match 这种非黑即白的指标，会把连续的提升看成突变。换成更细的部分得分指标，曲线可能就平滑了。
仁菜：所以涌现是假的？
桑多涅：是工程上能观察到的能力跃迁，但学术上对它是不是测量假象还有争议。这句话面试里原样说出来，比背三个例子有用。
仁菜：记下了。第二个例子呢？
桑多涅：In-Context Learning 本身。十五亿参数的 GPT-2 上完全看不到，一千七百五十亿的 GPT-3 上突然就有了，临界点在一千亿左右。
仁菜：第三个？
桑多涅：跨语言迁移。GPT-3 的训练数据里英文占百分之九十二，但训完之后，它能直接处理中文、日文、阿拉伯语，甚至冰岛语。
仁菜：没人教过它中文怎么说？
桑多涅：它从大规模多语言混合语料里，自己学会了语言之间的对应关系。
仁菜：那到底为什么会涌现？
桑多涅：业界给的工程经验叫 Scaling Law。第七集专讲，今天只记结论：模型规模、数据量、算力三者按比例同时放大，损失值会沿一条幂律曲线下降。
仁菜：所以越大越好？我们预算是不是该全砸在参数上——
桑多涅：……你这个毛病。超过某个规模，单纯堆参数的边际收益在递减。
仁菜：啊？
桑多涅：第三代 Llama 的八十亿模型，用十五万亿 token 训出来，效果比早期一千七百五十亿的 GPT-3 还好。
仁菜：数据规模超过参数规模带来的回报……
桑多涅：所以现在的趋势是参数不一定最大，但数据要够多、算力要够花。你那笔预算，砸法不对，一轮就没。
仁菜：懂了。那明天组会，三个本质区别我怎么说？
桑多涅：第一，传统 NLP 一任务一模型，各训各的；LLM 一个模型干所有事，因为它预训练学的是最通用的那件事。
仁菜：第二，传统 NLP 是判别式——吃文本吐标签；LLM 是生成式——吃文本吐更多文本，理解和生成在同一个模型里。
桑多涅：第三呢。
仁菜：规模到了会涌现出训练目标里没显式教过的能力，这在传统 NLP 上看不到。
桑多涅：够了。学费。
仁菜：有！我把现网那台推理机的负载扒了：日均请求两万一，峰值集中在上午十点和下午三点，P99 延迟一秒二。
桑多涅：……这算数据。两万一、双峰、P99 一秒二，带上机器型号一起报。
仁菜：知道啦，数字连着场景报，这是 S3 就立的规矩。
桑多涅：下一集，Transformer。你今天说的每一件事，底下都是它在扛。
仁菜：那我今晚先把架构图看一遍——
桑多涅：看不懂的。没有图能一次看懂它。明天带脑子来，别带图。我是说，炒瓜子也带上。
仁菜：……你刚才是不是差点说了句人话？我是仁菜，我们下集见。
