langchain第12集　Deep Research 的实现逻辑是什么？它适合哪些场景？
============================================================

仁菜：欢迎回来，我是仁菜——雪媚娘，两个。
桑多涅：……你排了多久。
仁菜：没排。下班顺路买的。
桑多涅：……哦。
仁菜：……怎么了嘛。
桑多涅：没什么。进度。
仁菜：……没有进度了。
桑多涅：……
仁菜：今天下午三点，对外演示做完了。
桑多涅：多久。
仁菜：四十二分钟——中间他们打断我十一次。
桑多涅：问到你答不上来的了吗。
仁菜：……有一个。他们问为什么不升那个大版本。
桑多涅：你怎么答的。
仁菜：我把那三十四个回归点报了一遍，然后说升级的收益是长期的，回归的风险是这周的。
桑多涅：……他们说什么。
仁菜：他们说这句话记下了，写进下季度的技术规划。
桑多涅：……
仁菜：……你笑什么。
桑多涅：我没笑。最后一题。
仁菜：诶？今天还有题吗？
桑多涅：十二集——这是第十二集。
仁菜：……哦。那你问吧。
桑多涅：Deep Research 的实现逻辑是什么，它适合哪些场景。
仁菜：……这个词我最近天天看到。
桑多涅：那你先答。
仁菜：就是多搜索几次，再让模型生成一篇更长的报告吧。
桑多涅：……搜索次数多，等于研究深入吗。
仁菜：……
桑多涅：研究范围怎么确定，子课题怎么拆，资料冲突怎么办，什么时候停。
仁菜：……四个问题我一个都答不上来。
桑多涅：再试一次。
仁菜：那……让十个 Agent 每人写一章，最后拼起来？Agent 越多越快！
桑多涅：十章拼起来，背景介绍会出现几次。
仁菜：……可能十次。
桑多涅：口径呢。
仁菜：……可能十种。
桑多涅：更合理的方式是并行收集独立子课题的证据，再由一个写作阶段统一综合。
仁菜：……那至少报告里链接多，就说明可靠吧？
桑多涅：……第三次了。
仁菜：……我知道，链接多不代表证据可靠。
桑多涅：那今天这题我先给你一句态度，你带着这句往下听。
仁菜：……什么呀。
桑多涅：这个词现在很热。
仁菜：嗯。
桑多涅：热词最容易考出真假。
仁菜：……怎么考。
桑多涅：你说得出它不适合什么场景吗。
仁菜：……
桑多涅：说得出适合的，是看过公众号——说得出不适合的，是用过。
仁菜：……那我今天先记这句。
桑多涅：先纠定位——它是 LangChain 核心包里的一个开关吗。
仁菜：……不是吗？
桑多涅：它是一类面向开放问题的研究型 Agent 架构。
仁菜：那官方那两个东西呢？我看到有两个名字。
桑多涅：open_deep_research 是参考实现，是一个具体的研究应用。
仁菜：另一个呢。
桑多涅：Deep Agents SDK，是更通用的 Agent 开发框架。
仁菜：……那能混着说吗。
桑多涅：不能混为一谈——一个是应用，一个是框架。说清这层就够了，不用背仓库实现。
仁菜：……那核心流程是什么呢。
桑多涅：六步。第一步，范围澄清。
仁菜：澄清什么呀。
桑多涅：用户只说研究某家公司的时候，你得确认他关注的是投资价值、技术路线，还是就业风险。
仁菜：……不然后面全跑偏。
桑多涅：第二步，形成 Research Brief。
仁菜：那是什么呢。
桑多涅：把用户目标、研究维度、时间范围、来源要求和最终交付形式，整理成稳定的成功标准。
仁菜：……成功标准。所以它不是提示词，是验收条件。
桑多涅：第三步，Supervisor 拆子课题。什么样的才适合并行。
仁菜：……相对独立的。比如分别研究三家公司的定价。
桑多涅：如果后一个问题依赖前一个结论呢。
仁菜：那就得串行。
桑多涅：第四步，Researcher 多轮使用搜索、企业检索或者 MCP 工具。每个研究员只处理一个主题。
仁菜：要保留什么吗。
桑多涅：来源信息——这是第五步的前提。
仁菜：第五步是什么呀。
桑多涅：把所有网页原文塞回 Supervisor 吗。
仁菜：……那上下文会炸吧。
桑多涅：压缩成带出处的关键证据——然后 Supervisor 检查 Brief 有没有被覆盖。
仁菜：有缺口呢。
桑多涅：继续补搜——有冲突也补。
仁菜：第六步就是写了吧。
桑多涅：由一个写作阶段统一组织论证、处理重复内容。还有一件事必须做。
仁菜：……什么呀。
桑多涅：把事实、推断和不确定性分开表达。
仁菜：……分开。
桑多涅：那现在回答一个更难的——为什么需要子 Agent。
仁菜：为了并行加速吧！
桑多涅：……不是。
仁菜：诶？
桑多涅：一个 Agent 同时研究多个主题会怎样。
仁菜：……搜索结果不断占用同一个上下文。
桑多涅：A 公司的价格、B 公司的安全文档、C 公司的失败请求，全混在一起。
仁菜：……模型反而更难关注当前证据。
桑多涅：所以拆子 Agent 首先是在做什么。
仁菜：……隔离上下文。
桑多涅：每个 Researcher 只处理一个子课题，最后只返回压缩后的结论和来源。
仁菜：……主 Agent 就不用背着全部搜索过程继续想了。
桑多涅：隔离做到了，并行才是自然结果。
仁菜：……顺序反了我就一直理解错了。
桑多涅：那 Agent 越多越好吗。
仁菜：……不是。模型调用、搜索费用、限流和协调成本都会涨。
桑多涅：所以关键仍然是什么。
仁菜：子课题能不能独立推进——不能为了并行而并行。
桑多涅：那怎么判断一份研究报告的质量——链接多算吗。
仁菜：……不算。那怎么看呢。
桑多涅：沿着来源、证据、结论，反向追查。先看来源值不值得信。
仁菜：什么样的更接近原始事实呀。
桑多涅：官方文档、论文、监管文件和一手资料。
仁菜：那十篇转载呢。
桑多涅：可能都来自同一篇文章。
仁菜：……那就不是交叉验证，是同一个声音响了十遍！
桑多涅：来源可靠之后呢。
仁菜：……还要确认它真的支持当前结论。
桑多涅：遇到冲突怎么办。
仁菜：继续追发布时间、统计口径和原始出处。
桑多涅：不能怎么做。
仁菜：……不能挑一个最符合预期的答案。
桑多涅：如果结论还是不稳呢。
仁菜：……那就回到过程里查。
桑多涅：查哪四样。
仁菜：搜索词有没有漏掉关键限定，子课题是不是重复了，停止条件是不是太早，工具失败之后有没有换有效来源。
桑多涅：评测的时候只看最终答案吗。
仁菜：……还要看研究轨迹、来源覆盖率、引用正确性、耗时和成本。
桑多涅：通用 Benchmark 呢。
仁菜：可以比版本，但不能代替企业自己的业务数据集。
桑多涅：……这句上一季你也说过一次。
仁菜：……没有 baseline 就是零分。
桑多涅：成本这块，它有两个维度。
仁菜：……哪两个呀。
桑多涅：宽度和深度——宽度是并行研究单元的数量。
仁菜：深度是……每个研究员和 Supervisor 最多迭代多少轮？
桑多涅：怎么控宽度。
仁菜：限制同时运行的研究单元。
桑多涅：怎么控深度。
仁菜：限制每个 Researcher 的工具调用次数，和 Supervisor 的补搜轮数。
桑多涅：单个分支有上限就够了吗。
仁菜：……不够。整项任务还要设总 Token、搜索费用和超时预算。
桑多涅：最后再补四样，系统才知道什么时候继续、什么时候降级、什么时候停。
仁菜：……失败重试、缓存、限流、取消策略。
桑多涅：安全上有一条，是这一整季的老朋友。
仁菜：……提示词注入！
桑多涅：网页和外部文档都是什么。
仁菜：不可信输入——可能诱导 Agent 泄露密钥，或者执行危险操作。
桑多涅：那研究工具应该怎么设计。
仁菜：优先只读——内部数据最小权限。
桑多涅：密钥呢。
仁菜：不要暴露给搜索或者沙箱环境。
桑多涅：高风险操作。
仁菜：人工审批，并且保留 Trace。
桑多涅：那金融、医疗、法律和安全决策呢。
仁菜：……只能辅助资料整理。
桑多涅：报告带了引用呢。
仁菜：带了引用也不能取消专家复核。
桑多涅：……好。那现在回答我一开始那句。
仁菜：……它不适合什么。
桑多涅：说。
仁菜：一次权威检索就能回答的实时事实，用它更慢更贵。
桑多涅：第二种。
仁菜：多个子任务必须严格共享中间状态的时候，强行并行只会增加冲突。
桑多涅：第三种。
仁菜：……数据源本身不可靠，或者根本没有访问权限。那研究 Agent 也变不出正确答案。
桑多涅：那什么时候才值得用。
仁菜：三个条件同时成立——问题开放到需要多轮搜索和动态调整方向。
桑多涅：第二。
仁菜：任务能拆出相对独立的子课题。
桑多涅：第三。
仁菜：报告的价值，能覆盖多轮模型和搜索的成本。
桑多涅：典型场景。
仁菜：竞品分析、技术路线调研、文献综述、供应商尽调、政策影响研究，还有企业内部资料和公开信息的联合分析。
桑多涅：……十二集，问完了。
仁菜：……
桑多涅：那这一季你学到的最重要的东西，说一遍。
仁菜：……不是 LCEL，也不是 LangGraph。
桑多涅：那是什么。
仁菜：……是分得清什么该造，什么不该造。
桑多涅：那你现在的分界线在哪。
仁菜：……凡是我造出来会和框架长得一样的，我不造。
桑多涅：另一半。
仁菜：凡是我不造就没人替我担责的，我必须造。
桑多涅：那怎么当场分。
仁菜：……问一句就行。这段东西出错的时候，是谁去道歉。
桑多涅：……
仁菜：是框架作者，就别造——是我，就得造。
桑多涅：……
仁菜：……怎么了。
桑多涅：……这句我没教过你。
仁菜：诶？
桑多涅：我教的是判据——这句是你自己的。
仁菜：……
桑多涅：……仁菜。
仁菜：嗯？
桑多涅：第一季第一集，你为了让我坐下，排了四十分钟买一个千层。
仁菜：……你还记得。
桑多涅：今天你没排队。
仁菜：……雪媚娘是我下班顺路买的。
桑多涅：因为你现在不需要用甜点买我的时间了。
仁菜：……
桑多涅：陈述事实。
仁菜：……那这五季的甜点账，一共多少样啊。
桑多涅：七十七。我记着。
仁菜：……你连这个都记！
桑多涅：……还有一件事。
仁菜：……你说。
桑多涅：下一季你想讲什么。
仁菜：……诶？
桑多涅：我问你。
仁菜：……前四季都是你定题的呀。
桑多涅：这一季我跟着你学的东西，比你从我这儿拿走的多。
仁菜：……
桑多涅：所以这次你定。
仁菜：……那我想回头讲第一季。
桑多涅：……第一季？
仁菜：第一季那十六道题，我现在的答案，和那时候不一样了。
桑多涅：哪里不一样。
仁菜：……第一集我说 Agent 就是会调工具的大模型。今天我知道那句话漏掉了状态、边界和谁去道歉。
桑多涅：……
仁菜：同一道题，隔了五季再答一遍——这个能做吗。
桑多涅：……能。
仁菜：那你还来吗。
桑多涅：……甜点标准别降。
仁菜：……那就是来。
桑多涅：下一句。
仁菜：……那么，《Agent 面试课》第五季，框架与工程化，十二集，全部完结。这一季我没学会造更多东西，我学会的是什么不用自己造。
桑多涅：还有一句。
仁菜：……还有，出错的时候会去道歉的那个人，永远得自己写那段代码。
桑多涅：……嗯。
仁菜：我是仁菜，我们下季见！
桑多涅：下季见。
