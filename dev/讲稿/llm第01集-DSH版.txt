仁菜：欢迎回来，我是仁菜。糖炒栗子，刚出锅的，路上没忍住先剥了三颗。
桑多涅：名单呢。
仁菜：……案子撤了，名单没交出去。行政调了监控，拿小方的是导师本人，他一直当那是下午茶点心。
桑多涅：……被冤枉的那位呢。
仁菜：实习生小蒋。我咬定是他，咬了一整天——下午专门去道了歉，赔了杯奶茶，二十六块。
桑多涅：下回先调监控再张嘴。行了，正事——立项会开完了吧。
仁菜：评测基座。公司要在「自建大模型」和「买 API 服务」之间做决定，CTO 说三个月后凭数据说话——这事归我。
桑多涅：那我在这季里是谁。
仁菜：公司外聘的技术评审，验收单上盖你的章，一场一结，公对公——至于私下那份合同，照旧，情报换甜点。
桑多涅：两本账别记混就行。今天的甜点。
仁菜：哦对，正事里的正事——导师早上问我「什么是大语言模型」，我答：就是 ChatGPT 那种，参数特别多、能聊天的。
桑多涅：Siri 也能聊天。它是大语言模型吗。
仁菜：……不是。它走的是语音助手那套老架构，后面挂的是规则和检索。
桑多涅：「参数特别多」，多到多少算多。
仁菜：亿级以上？训练数据也特别多，能干各种 NLP 任务——
桑多涅：BERT 也有几亿参数。它是大语言模型吗。
仁菜：……也不是。可我这么一说，Siri 和 BERT 全被框进来了——这句话等于什么都没说啊。
桑多涅：那是结果，不是本质。再给一次机会，这回从「模型怎么干活」的角度说。
仁菜：干活的角度……LLM 不分步骤，一个模型端到端，文本进文本出？
桑多涅：「端到端」这三个字，二零一五年就有人讲了。当年 LSTM 是端到端，BERT 接个分类头也是端到端——你这答案放十年前都不算新。
仁菜：……一个早上死了三回。
桑多涅：这题是底子，后面二十多集全摞在它上面。坐直了，从 LLM 出现之前的世界讲起。
桑多涅：传统 NLP 干活是流水线：一个任务拆成几段，每段养一个专门的模型。不是前人笨，是当时的模型小，复杂问题只能拆成简单子问题分开训。
仁菜：拆成什么样？拿我们客服举例试试——
桑多涅：你来拆。
仁菜：第一步分词，「我想退货」拆成我、想、退货；第二步词性标注，「退货」是动词；第三步命名实体识别，抓订单号和商品名；第四步意图分类，判断咨询还是投诉；第五步去知识库匹配预设答案——五步，五套模型。
桑多涅：五套模型，五份标注，五个团队。光第一步就有坑：中文跟英文，差在哪。
仁菜：中文没有空格啊！比如「南京市长江大桥」——是南京市、长江大桥，还是南京、市长、江大桥？
桑多涅：这种歧义靠规则救不了，得再养一个专门的分词模型来判；分词模型又得靠人工标注喂着。那碰上词表里没有的新词呢。
仁菜：比如「绝绝子」这种？它就懵了吧。
桑多涅：就懵了。这叫未登录词，行话 OOV。每一步都有自己的模型、自己的标注规范、自己的坑，谁也帮不了谁。
仁菜：而且这个病我有既视感——上季见过的：检索错一步，生成就跟着瞎编。流水线也一样吧？分词错了，词性跟着错，实体识别跟着错，最后意图分类全错。
桑多涅：对，错误会累积传导，救不回来——整条流水线又长又脆。还有一笔账你没算：换个领域呢。
仁菜：客服换医疗……实体全变了！电商抓商品订单，医疗抓药名症状——模型基本得全部重训吧？
桑多涅：一个公司想干三个领域，就养三套团队。任务越细分，模型越多；模型越多，标注越贵；标注越贵，迁移越难。整个行业就在这个圈里打转。
仁菜：然后呢，二零一八年出了 BERT。
桑多涅：它的招法叫「预训练加微调」，两阶段。预训练在海量无标注文本上做，维基加图书，约三十三亿词；干两件事：MLM，随机遮住句子里百分之十五的词，让模型看上下文猜被遮的是什么；NSP，给两个句子，判断是不是连着的。
仁菜：都不用人工标注，所以吃得起海量数据。训完之后呢？
桑多涅：训完它就「看懂文字」了——学到了通用的语言表示。下游任务在它上面接一个小任务头，用少量标注微调一下，各个任务的成绩单全被它刷了一遍，整个领域为之一振。
仁菜：那不就任务统一了吗？一个模型走天下——
桑多涅：它停在一半。特征通用——一个 BERT 服务多个下游任务，做到了；任务统一——不同任务还是要各自的微调副本，没做到。两个原因。
仁菜：第一个？
桑多涅：BERT 的输出是「表示」，不是「文本」——它吐出来的是每个词的向量。拿去做分类，得接分类头；做实体识别，接序列标注头；做问答，接抽取式问答头。头不同，标注不同，训练过程也不同。一个 BERT 进了公司，能派生出十几个微调副本。
仁菜：等等——那不就是变相的流水线吗？一个底座，N 个头，各管一摊，标注还是贵，错误还是会传导。
桑多涅：看出来了。第二个原因更硬：BERT 不会写作文。
仁菜：为什么啊，它那么大一个模型。
桑多涅：它的训练目标是填空题——每次只猜一个被遮住的词。连续生成一百个词这种事，它没学过。所以翻译、写作、对话这些活，当时还得靠 GPT-2、T5 那条线。理解它做到了极致，生成是短板。
仁菜：那把所有任务真正收归一个接口的，是 GPT 系列。
桑多涅：对。它把所有 NLP 任务统一成一件事——这件事说出来一点都不唬人：预测下一个 token。
仁菜：……就这？
桑多涅：就这。这个训练目标叫 CLM，因果语言模型。给一句「我喜欢吃苹果」，它要学会：看到「我」猜「喜」，看到「我喜」猜「欢」，看到「我喜欢」猜「吃」。从左到右，一步一步猜。
仁菜：每一步都依赖上一步的输出——这就是自回归吧？
桑多涅：对。GPT、Claude、Qwen、DeepSeek，本质都是自回归加因果掩码的语言模型。
仁菜：可是这么朴素的训练目标，怎么就什么任务都能干了？
桑多涅：你说。翻译怎么干。
仁菜：Prompt 写「把下面这句翻成英文：我喜欢你」，让它接着往下写——它顺着就输出 I like you 了！
桑多涅：分类呢。
仁菜：「下面这条评论是正面还是负面？这家店太黑了。答：」——它接着猜的那个词，就是「负面」！
桑多涅：总结、写代码，同理。所有任务都被「Prompt 加续写」这一个接口收编了——换任务不用换模型，换个说法就行。
仁菜：我还是有点不服——凭什么猜字猜得多，就能学会翻译和算术？
桑多涅：因为要在不同上下文里都猜准，它就必须学到语法、事实和推理。要预测「北京是中国的」下一个词，它得知道北京是首都。
仁菜：要预测「如果 x 等于二，那么 x 的平方等于」，它就得会算数吧？要预测代码的下一行，它就得懂编程逻辑。
桑多涅：所有这些能力，都是被「预测下一个 token」这个看似简单的目标逼出来的。再配两个杠杆：数据和规模。
仁菜：数据杠杆我知道一点——互联网上的文本天然就是训练数据，不用人工标！
桑多涅：对。GPT-3 用了三千亿 token，Llama 三代用了十五万亿；BERT 当年才几十亿词，翻了几千倍。
仁菜：规模杠杆呢？BERT 三亿参数，GPT-3 一千七百五十亿——那 GPT-4 肯定是万亿级！
桑多涅：停。GPT-4 的参数量官方没公开过，外界只能估。把「万亿级」当确定事实讲，遇到懂行的当场穿。稳的说法是：模型规模、训练数据、算力一起放大之后，「预测下一个 token」这件事被推到了新的境界。
仁菜：记住了，没公开的数不背……诶，还有个怪事我早就想问了：Prompt 里给几个例子，它就会干新任务了，参数一个都没动——
桑多涅：上下文学习，行话叫 ICL。Prompt 里喂几个「中文翻英文」的例子，再给一个新的，它就能接着翻。这个能力 GPT-3 之后业界才发现的——现在满大街的 Prompt 工程，就是打这儿来的。
仁菜：模型看着例子，自己推出了「这是中译英」的模式……那这能力是一直都有吗？
桑多涅：不是。GPT-2 那会儿完全看不到，GPT-3 出来突然就有了，临界点在一千亿上下。这类「过了某个规模就突然冒出来」的能力，叫涌现。
仁菜：还有更玄的例子吗？
桑多涅：多步算术。谷歌二零二二年测五步计算的应用题：八十亿参数以下的模型，准确率几乎是零；六百二十亿，百分之五；五千四百亿的 PaLM，直接跳到百分之六十。
仁菜：中间没有过渡？！那不是量变，是质变啊！
桑多涅：这里留个心眼：有研究认为一部分「突变」是评测指标造成的——exact match 这种非黑即白的指标，会把连续进步看成跳变；换成部分得分这种细指标，曲线可能就平滑了。
仁菜：所以涌现到底算真的吗？
桑多涅：工程上真能观察到跃迁，学术上对它是不是测量假象还有争议。这句话面试里原样说出来，比背三个例子值钱。第三个例子：跨语言。GPT-3 的训练数据英文占九成二，训完直接会中文、日文、阿拉伯语，没人显式教过。
仁菜：多语言语料混在一起，它自己学会了语言之间的对应关系……等一下，预言清单！立项会我立的第一条预言，现在就该写进清单：「参数越大，模型一定越聪明」。
桑多涅：记。然后我当场给你毙了：Llama 三代八十亿的模型，十五万亿 token 喂出来，比一千七百五十亿的 GPT-3 还好。你这条预言，活不过今天。
仁菜：第一天就折了一条？！
桑多涅：超过某个规模，单纯堆参数的边际收益在递减。业界的经验律叫 Scaling Law：模型规模、数据量、算力按比例一起放大，损失值沿着幂律曲线往下掉；数据和参数还有配比，七百亿参数大约配一点四万亿 token，行话出自 Chinchilla 那篇论文。趋势是参数不必最大，数据要够多，算力要够花。
仁菜：……那对我那个基座反而是好消息：不用追最大的模型，力气全花在怎么测上。
桑多涅：会算账了。学费。
仁菜：交！立项纪要里 CTO 的原话：「三个月后，自建还是采购，凭基座的数据定。」这一季每一集，都是在给这句话攒证据。
桑多涅：……这算数据。三个月，一句话授权，外加一个外聘评审。再补一条：基座得能查出问题出在哪一层——不然三个月后你拿什么说服人。
仁菜：那三本质区别我收个尾：工程上，拼积木变统一系统，一个模型组服务全公司；范式上，判别式变生成式，输入文本输出更多文本，理解和生成在同一个模型里；能力上，涌现——没人显式教过的任务，它自己会了。
桑多涅：再补一层产业账：过去做项目，先想数据怎么标、选哪个 BERT 变体、超参怎么调；现在先想 Prompt 怎么写，再想要不要加外部知识，最后才轮到微调。工程师的技能清单，整个换了一遍。
仁菜：所以大模型应用工程师这个岗位才冒出来……明天的预言我都想好了：Transformer 的图，我一定看得懂！
桑多涅：记上。明天的甜点，海棠糕。
仁菜：海棠糕好嘞。预言清单还有一整页空白——我是仁菜，我们下集见。
桑多涅：栗子壳收拾干净再走。
