langchain第11集　LangChain 大版本升级带来了哪些核心变化？
============================================================

仁菜：欢迎回来，我是仁菜——冰粉，两碗，我买的。
桑多涅：……你居然有空排队了。
仁菜：没排。楼下便利店的。
桑多涅：……那也算。进度。
仁菜：只剩七天。
桑多涅：那你今天心不在焉是为什么。
仁菜：……组里有人提了个 PR。
桑多涅：说。
仁菜：他要升大版本——理由是新版本有 middleware，更好。
桑多涅：你怎么回的。
仁菜：……我还没回。我在想我一年前会怎么回。
桑多涅：……一年前你会怎么回。
仁菜：……我会说升啊！更好为什么不升！
桑多涅：现在呢。
仁菜：……现在我不敢答，因为我说不出理由。
桑多涅：那今天这题正好——LangChain 的大版本升级，带来了哪些核心变化。
仁菜：……支持的模型和向量数据库越来越多？功能更丰富了。
桑多涅：……这些只是表面。
仁菜：诶？那深的是什么呀。
桑多涅：为什么要把 langchain-core 和模型集成包拆开。
仁菜：……
桑多涅：为什么又引入 Runnable、LangGraph 和 middleware。
仁菜：……我只知道它们是什么，不知道为什么。
桑多涅：那你再答一次。
仁菜：……因为旧 API 不好用，所以新版本把旧的 Chain 全删了？
桑多涅：……又错。
仁菜：……全删了不对吗。
桑多涅：旧能力主要被移到 langchain-classic，不是全部删除。
仁菜：……那存量项目还能跑。
桑多涅：所以这题真正在考什么，你现在能猜到吗。
仁菜：……不是背哪个小版本加了什么 API 吧。
桑多涅：它在考 LangChain 为什么从一个包罗万象的工具箱，长成了一套分层架构。
仁菜：……分成哪几层呢。
桑多涅：稳定核心协议、独立模型集成、高层 Agent API、LangGraph 运行时。
仁菜：……四层。
桑多涅：那先讲它为什么要改——早期的包结构是什么样，你想象一下。
仁菜：……模型、向量库、工具、Retriever，还有一大堆预制的 Chain，全挤在一起？
桑多涅：验证想法很方便。项目一大呢。
仁菜：……第三方 SDK 更新一次，会怎么样。
桑多涅：可能牵动整个依赖树。
仁菜：……那真的很痛。
桑多涅：依赖只是第一层——第二层，不同 Chain 的调用和组合方式并不统一。
仁菜：……那开发者就得记越来越多专用 API。
桑多涅：第三层，复杂 Agent 的执行循环藏在执行器内部。
仁菜：……藏起来了就插不进东西。
桑多涅：插不进分支、审批和恢复——所以功能越加越多，核心职责反而越来越模糊。
仁菜：……那大版本演进的重点就不是加功能。
桑多涅：是重新划分边界——哪些协议需要保持稳定，哪些集成应该独立更新，哪些流程应该交给更底层的运行时。
仁菜：……那第一条主线就是拆包吧。
桑多涅：核心里放什么。
仁菜：消息、模型、Tool、Runnable 这些协议。它们应该尽量稳定。
桑多涅：外面放什么。
仁菜：第三方模型和向量库，迁到社区包或者独立的集成包。
桑多涅：为什么要分开。
仁菜：因为厂商 SDK 变化很快，核心协议不该跟着它抖。
桑多涅：两种迭代节奏放在同一个包里会怎样。
仁菜：……互相影响。
桑多涅：拆开之后，项目只装真正需要的集成，某个模型 SDK 升级也不会震动整个框架。
仁菜：那面试要背包名吗？
桑多涅：不用。记住八个字就够 —— 稳定内核，释放边缘。
仁菜：……稳定内核，释放边缘。
桑多涅：第二条主线，Runnable 和 LCEL。它们统一了什么。
仁菜：……组件的调用方式吧。Prompt、Model、Parser 都有一致的 invoke、batch、stream 和异步接口。
桑多涅：在这之前是什么样。
仁菜：……一大堆 Chain 类，调用方式和扩展方式还不完全一样。
桑多涅：那管道符是重点吗。
仁菜：……不是吗？
桑多涅：重点是组合完之后，那个整体仍然遵循 Runnable 协议。
仁菜：……所以同步、异步、批处理、流式和追踪，还是同一套接口。
桑多涅：这代表框架从什么转向了什么。
仁菜：从大量预制类，转向少量标准协议加组合。
桑多涅：那确定性流程该用什么。
仁菜：……用 Agent 吧？
桑多涅：步骤固定的流程，Runnable 和 LCEL 往往比 Agent 更容易测试和控制。
仁菜：……我们那个日报生成，昨天你也是这么说的。
桑多涅：第三条主线你昨天刚学完——传统 Agent 执行器在内部跑什么循环。
仁菜：模型判断、调用工具、再次判断。
桑多涅：加进规划、反思、并行分支、人工审批和故障恢复之后呢。
仁菜：……隐藏的循环就改不动了。
桑多涅：LangGraph 的思路是把它摊开成什么。
仁菜：State 加 Node 加 Edge。State 保存消息和业务进度，Node 执行模型、工具或者普通业务逻辑。
桑多涅：Edge 呢。
仁菜：决定结果接下来流向哪里。
桑多涅：摊开之后多了什么。
仁菜：……检查点能保存运行状态，所以暂停恢复、人工介入和长时间执行才有基础。
桑多涅：那它是来替换 LangChain 的吗？
仁菜：不是。这句我这两天说了很多遍了。
桑多涅：第四条主线，v1 聚焦到哪儿。
仁菜：Agent——create_agent 成为高层入口。
桑多涅：横切能力交给谁。
仁菜：middleware——动态提示词、工具控制、摘要、重试和人工介入。
桑多涅：为什么不能每加一项能力就重写一遍循环。
仁菜：……那高层入口很快就失去意义了。
桑多涅：旧 Chain、Retriever、Indexing、Hub 这些去哪了。
仁菜：主要迁到 langchain-classic。存量项目还能跑，可以渐进迁移。
桑多涅：所以四条主线的共同方向是什么。
仁菜：……不是增加更多类。
桑多涅：是什么。
仁菜：稳定核心抽象、解耦第三方集成、统一组合协议，再把复杂 Agent 交给可持久化、可恢复的图运行时。
桑多涅：……嗯。还有一个小的，很多人会花太多时间在上面。
仁菜：……什么呀。
桑多涅：内部数据模型迁到了 Pydantic 的第二代，并且停用了第一代的兼容层。
仁菜：这个重要吗？
桑多涅：工具 Schema、结构化输出和配置对象都依赖它，所以它是重要的迁移背景。
仁菜：那要展开讲吗？
桑多涅：不用展开全部版本差异——说清它统一了数据模型与校验基线，旧项目升级要检查导入路径和模型定义，就够了。
仁菜：……那时间应该花在哪儿呢。
桑多涅：拆包、Runnable、LangGraph 和 v1 的 Agent 架构。那四样才体现长期方向。
仁菜：……那回到那个 PR 吧。到底该不该升呀。
桑多涅：我不替你判——你先说，跨大版本升级，第一步做什么。
仁菜：……先读迁移指南？
桑多涅：在读之前还有一步。
仁菜：……什么呀。
桑多涅：锁定当前依赖和可复现环境。
仁菜：为什么这个要放在最前面。
桑多涅：多个包同时变化的时候，你很难判断问题是从哪里开始的。
仁菜：……那就全乱了。第二步呢。
桑多涅：顺着新的分层检查兼容关系——langchain、LangGraph 和模型集成包，各自有各自的更新节奏。
仁菜：确认完版本组合，再改导入路径和内部 API。
桑多涅：怎么改。
仁菜：……一次全改完，然后跑？
桑多涅：小步修改，小步运行——不要等所有代码都改完，才第一次启动。
仁菜：……启动起来了就算升完了吧。
桑多涅：……你再想一遍。
仁菜：……不算。启动只说明导入问题解决了。
桑多涅：那还有什么必须分别回归。
仁菜：工具调用、结构化输出、流式响应，还有持久化。
桑多涅：为什么是这四样。
仁菜：……因为这些边界最容易被协议和运行时的变化影响。
桑多涅：有副作用的路径呢。付款、发消息那些。
仁菜：……先在隔离环境验证幂等。
桑多涅：然后。
仁菜：再小流量发布——不能一次升级就把重复执行带进真实业务。
桑多涅：最后一条，生产项目最容易栽。
仁菜：……哪一条。
桑多涅：主包的稳定承诺，不会自动覆盖社区集成、合作伙伴包和实验性 API。
仁菜：……所以要固定依赖版本。
桑多涅：并且尽量建立在公开稳定接口之上。现在，判你那个 PR。
仁菜：……我下午已经算过了。
桑多涅：说数。
仁菜：按这四类回归点数，我们这个项目一共三十四个。工具调用十九个，结构化输出六处，流式四处，持久化五处。
桑多涅：要几天。
仁菜：……最快四天。而且这四天里不能同时改业务。
桑多涅：你还剩几天。
仁菜：七天。
桑多涅：那答案呢。
仁菜：……交付后升。不是不升，是不在这七天里升。
桑多涅：理由用一句话。
仁菜：升级的收益是长期的，回归的风险是这周的。
桑多涅：……这句可以写进你的 PR 评论。
仁菜：……还有一件事我想说。
桑多涅：说。
仁菜：那个 PR 里其实混了两种升级。一种是大版本，一种是某个集成包的小版本安全补丁。
桑多涅：那两种一样吗。
仁菜：……不一样！安全补丁那个反而该马上升，它的回归面只有一处。
桑多涅：……所以该跟的和不该跟的，要分开判。
仁菜：……我差点一起否掉了。
桑多涅：那这一条比前面那条更值钱。学费。
仁菜：三十四个回归点，四天，对七天——还有那个被我差点一起否掉的安全补丁。
桑多涅：这算数据——而且这是你第一次自己判完再来问我。
仁菜：……
桑多涅：最后一句提醒，跟这道题的性质有关。
仁菜：……什么性质呀。
桑多涅：这题里所有的版本号，都会过期。
仁菜：……那我背它干嘛呀？
桑多涅：所以别背，也别在面试里报当前最新的补丁版本。
仁菜：报了会怎样呢。
桑多涅：版本号会变——你今天记住的那个数字，三个月后就是错的。
仁菜：……而且显得我在背新闻，不是在做工程。
桑多涅：记方向——方向不会过期。
仁菜：……这句你上一季说过。
桑多涅：上一季说的是模型选型，这一季说的是框架版本。
仁菜：……同一句。
桑多涅：那你把方向说一遍，这题就收完了。
仁菜：稳定核心、解耦集成、组合确定性流程、图化 Agent 运行时。
桑多涅：这四句同时回答了什么。
仁菜：……既回答了升级了什么，也解释了为什么要升级。
桑多涅：……嗯。明天交付。
仁菜：……明天？！
桑多涅：你还剩七天，但你们的对外演示是明天。你自己说的。
仁菜：……我昨天说的。
桑多涅：明天讲 Deep Research。雪媚娘。
仁菜：……那我明天带。演示完我请。
桑多涅：……随你。下一句。
仁菜：……我是仁菜，我们下集见！
