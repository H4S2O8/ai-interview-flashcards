# S4《预测下一个 token》——DSH 独立构思版（llm 22 集）

> 与 Claude 版（s4_plan.md）并行对照用。前提、仪式、账本、结局钩子均为独立设计，
> 与其「等价交换 / GPU 余额 / 烤红薯」路线刻意区分。

## 前提（承 S3E20 我埋的钩子）

- 仁菜转正第一周，接 P0：**给大模型本身建评测基座**。立项会定调：公司「自建大模型 vs 采购 API」，三个月后凭基座数据定——这季每一集都在给这句话攒证据。
- 桑多涅身份升级：**公司外聘技术评审**（验收单盖章，公对公）+ 私下甜点合同照旧（情报换甜点）。一个在里面有系统有预算，一个在外面有方法论。
- 冷开场结 S3 尾案：冰箱鲜奶小方案 → 凶手是导师（以为是行政下午茶）。仁菜凭直觉冤枉实习生小蒋一天——**「猜要付道歉，测才是方法论」**，本季题眼第一句。
- 实习生小蒋常驻背景板（不上桌）：仁菜把 S3 的三句话往下传，发现「教」比「学」难，给 E21 评测集设计提供第二视角。

## 季签名仪式：预言清单对赌

- 每集仁菜对模型行为立一条直觉预言（「温度越高越有创造力」「量化一定掉点」「参数越大越聪明」……），写进基座的「预言清单」。
- 随后某集用实测/论文数据结算：兑现打勾，翻车划掉。结算集输家带次日甜点。
- 结局（E22）：全季清单结算，仁菜命中率约六成——**桑多涅输了对赌，第一次按合同带甜点**；最后一条预言不结算，「我自己留着」。

## 三幕结构（22 集）

### 第一幕「地基」（E1–E7）：模型是什么
E1 LLM 是什么/E2 Transformer/E3 注意力/MQA/GQA/E4 位置编码/E5 分词器/E6 训练/E7 Scaling Law 与涌现。
- 基座进度：需求盘点 → 预言清单上线（E1）→ 第一版测度集（E7）。
- 毛病变体①（E7）：「把预算全砸参数」→ 边际收益递减打脸。

### 第二幕「驯化」（E8–E13）：把通用模型变成自己的
E8 微调方案/E9 LoRA/E10 RLHF·DPO·GRPO/E11 DPO vs PPO/E12 解码策略/E13 温度·Top-P·Top-K。
- 基座进度：评判标准之争（「好回答」怎么定义，E10 引入 LLM-as-Judge 雏形）。
- 毛病变体②（E12）：「解码直接上最复杂的 Beam Search」→ 场景错配打脸。
- 软化①（E10）：桑多涅讲到「对齐」时停了一下——「把力气花在让输出可信上，比花在显得聪明上值。」（对仁菜，也是对 S3 的自己说）。

### 第三幕「上线」（E14–E19）：成本与可信
E14 KV Cache·Prompt Caching/E15 量化 INT8·INT4·AWQ·GPTQ/E16 Prompt 工程/E17 CoT/E18 幻觉/E19 MoE。
- 基座进度：成本维度并入（E14 缓存账、E15 量化账）；幻觉测度（E18）直接复用 rag 季的「证据编号」基线。
- 软化②（E14）：「缓存的意义是——付过钱的，别再付一遍。」桑多涅承认 S1 起的笔记她也留了一份。
- 毛病变体③（E15）：「全 INT4 压到底」；变体④（E19）：「立刻改 MoE 架构」。

### 第四幕「交付」（E20–E22）
E20 部署（vLLM 等）→ 基座上线灰度；E21 评测指标 → **基座 1.0 交付，CTO 验收**；E22 模型选型对比 → 用基座出报告，「自建 vs 采购」给出答案。
- 毛病变体⑤（E22）：榜单控复发（呼应 rag E6），被自己的基座数据按住——「看榜单前，先看你的测度集里有没有你自己的场景」。
- S5 钩子：基座交付后发现，编排、记忆、工具这些轮子早有现成框架——「别人的轮子」→ langchain 板块。

## 与 Claude 版的刻意分野

| 维度 | Claude 版 | 本版 |
|---|---|---|
| 主线 | 自建能力 + GPU 预算，每集报余额 | 评测基座（承 S3E20 钩子），预言清单对赌 |
| 双方关系 | 桑多涅有事求仁菜（等价交换） | 公对公外聘评审 + 私下合同照旧 |
| 冷开场 | 加班没买着甜点 | 冰箱案结案（凶手=导师），「猜 vs 测」定调 |
| 仪式 | 学费照旧 | 学费升级为「预言 → 实测结算」 |
| 结尾 | 甜点标准继续涨 | 桑多涅首次按合同输掉对赌带甜点，钩子接「别人的轮子」 |
