## 0. 一句话定位

> **S1 学会「答」，S2 练到「过」，S3 逼到「做」。**

RAG 是全系列最工程的板块。S2 结局仁菜一面通过、offer 在手——S3 就是 **试用期三个月 +
转正答辩**：公司派她做企业知识库助手（RAG），每集的面试题同时是她当天要干的活。
桑多涅从出题人变成验收人。

- **deck**：`rag`（articles.json `decks.rag`，20 题，原文共 76292 字）
- **预估成稿**：~46k 字 / ~135 分钟 / ~700 次 TTS（S2 实测 76k 源字 → 41.9k 成稿）
- **硬约束不变**：1 题 = 1 集（deck+qno 绑定卡片）、无半角 `"` `\`、无舞台指示、
  数字全中文、探针逐集人工核

## 1. 剧情线四件套（S3 版，对照手册 §4 的四条线）

| 线 | S3 设计 |
|---|---|
| **阶段性目标** | **里程碑制，不用倒计时**（避免和 S2 撞型）：入职第一周（E1–3）→ 数据入库（E4–5）→ 选型采购（E6–8）→ 检索链路（E9–13）→ 内测优化（E14–16）→ 质量汇报（E17–18）→ 运维交接（E19）→ **转正答辩（E20）**。台词里用「第 N 周」锚时间，别精确到天 |
| **桑多涅的动机** | S2 结尾她说了「下一季，涨价」。新合同：**马卡龙涨价她吃腻了，本季收情报**——每集仁菜必须带一条公司内部一手数据（量级、延迟、报价、事故）当学费。傲娇研究员收集行业情报，且让三道经验题（E9/18/20）的素材天然长在剧情里 |
| **仁菜的成长** | 老毛病「一看到更强的方案就想选它」的新战场：**选型冲动撞上真实成本**。变体三连：E6 看到新 embedding 模型就想全换、E13 多路召回全上、E15 复杂范式冲动——E15 这次**她自己刹住**（自我纠错，成长完成时刻）。全季高光 **仁菜赢了**：E8 她用现场数据否掉桑多涅的推荐，桑多涅回「陈述事实：这次你的数据比我的经验准」，然后交出私藏选型清单（软化①的因果链） |
| **甜点账本** | 涨价 = 换赛道到**老字号/季节限定**（梗：涨价涨的是排队时长）。季节跟着试用期走（夏末→秋→初冬），中秋档出现咸点心是桑多涅亲自钦点的特例（权力反转笑点，不算软化点）。E20 蝴蝶酥回归闭环（S3E1 同款） |

## 3. 软化点（全季仅三次，手册纪律）

- **E8**：选型被仁菜的数据说服 → 交出私藏选型清单
- **E15**：深夜救火，仁菜带热的酒酿饼来，桑多涅分了一半
- **E20**：答辩日，桑多涅自己带蝴蝶酥到场外等——第一次她带东西来

## 4. 经验题三集的态度变体（桑多涅的「别装」要说三遍、三种说法）

- **E9**（量级/瓶颈）：「没做过生产级就报 demo 的数，把『没做过』说在前面，不扣分」
- **E18**（量化效果）：「指标背得再熟，没 baseline 就是零分——你的分母是什么？」
- **E20**（最难的地方）：「答『技术』两个字，就说明你没干过」

## 6. 交接清单（新 session 开工顺序）

1. **工作区**：`~/Projects/flashcards-dev`（dev worktree，master 的 dev/ 已清空——
   别在 master 工作区起草）
2. **生成脚本先改一行**：`dev/gen_podcast_renna.py` 的
   `PREFIXES = {"agent": "", "tools": "tools"}` 加 `"rag": "rag"`，
   `EPS_STORE` 初始化加 `"rag": {}`，`--deck` 的 choices 加 `"rag"`。
   音频命名 → `audio/renna/rag01.mp3`，讲稿 → `dev/讲稿/rag第NN集.txt`
3. **起草**：`dev/草稿/s3_eps.py`，结构照抄 `s2_eps.py`（`EPS[n] = (title, [(role, text)...])`
   + `KEY[n]` 探针 + `__main__` 体检）。探针 tips：
   - KEY 按中文写法列（二零二五、零点八五、四二九），假阴性逐条人工核
   - 成稿字数以 gen 脚本口径为准（探针口径含标题，略高）
4. **验证**：探针全绿 → `.venv/bin/python dev/gen_podcast_renna.py --deck rag --dry-run`
   （制作意图正则体检必须 0 问题）→ `--txt-only --deck rag`
5. **合成**：`--deck rag` 全量 TTS（`.env` 的 `FISH_KEY`；缓存 `dev/.tts-cache/`，
   失败重跑不重复计费）→ 时间轴与 mp3 实测逐集差应 ≤50ms、字数/346 偏差 ±10% 内
6. **发布**：手册 §8——mp3 传 R2（wrangler OAuth 在 `/tmp/xdg-config`，重启丢就重 login；
   账号 ID `CF_ACCOUNT_ID_REDACTED`，桶 `ai-flashcards-audio`，键=仓库路径），
   逐集公网 200+字节数校验；json/lrc 回流 master 工作区提交 + `script.json` version 加一
   （当前 master 是 2.5.10）+ 推送
7. **dev 分支每完成一个阶段提交一次**；master 只收发布提交
