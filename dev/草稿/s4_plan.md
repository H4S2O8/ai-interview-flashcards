## 0. 一句话定位

> **S1 学会「答」，S2 练到「过」，S3 逼到「做」，S4 撞上「不会」。**

S3 结局仁菜转正，桑多涅撂下「你接的不是题库——是 P0」。S4 就是这个 P0：
公司要自建大模型能力，仁菜第一次面对**没有比喻能一次讲明白的东西**。

前三季她的错都是「想当然」——看到更强的就想上，被数据打回。**S4 的错换了一种：
她是真的跟不上。**Transformer 内部、位置编码、MoE 路由、量化误差，这些东西
不存在「哦我懂了」的瞬间，只有反复啃。

- **deck**：`llm`（articles.json `decks.llm`，22 题，原文共 123606 字 —— rag 的 1.6 倍）
- **预估成稿**：按 rag 实测口径（知识压缩比 1.6–2.6x）推，约 55k–60k 字 / 165–180 分钟
- **桑多涅身份要改**：`gen_podcast_renna.py` 的 `GUEST_ROLE` 改成
  「愚人众执行官第七席「木偶」｜资深大模型工程研究员｜傲娇但专业，一针见血」

## 1. 剧情线四件套（S4 版）

| 线 | S4 设计 |
| --- | --- |
| **阶段性目标** | **预算制**。S1 用倒计时、S3 用里程碑，这季用**烧钱的时钟**：公司批了一笔 GPU 预算，烧完就停。每集台词里出现一次「还剩多少」，逼着每个技术选择都得报代价。这条线和 llm 板块「什么都贵」的性质天然契合，也正好喂桑多涅那句判据——能说出代价和边界的人，才像做过项目的人 |
| **桑多涅的动机** | **第一次轮到她有求于人**。S3E8 她被仁菜的数据说服过一次，这季她手上有个卡了很久的问题，需要真实生产环境的数据来验证——所以是**交换**，不再是单向教学。她嘴上仍然是「学费」，但两个人都知道这次不一样。这个位置变化是 S3E8 那条因果链的自然下一步 |
| **仁菜的成长** | 老毛病「看到更强的就想上」在这个板块会致命（想上最大的模型、最新的量化、最花哨的 Post-Training），前段照常翻车。但**新课题是「承认不会」**——第一次学会说「这块我没吃透，我只能讲到这里」。这条直接把手册的制作纪律（宁可讲透一半，但要诚实说还有几个点没展开）变成人物弧线，一举两得 |
| **甜点账本** | **倒转**。S3E20 桑多涅第一次自己带东西来。S4 顺势接住：仁菜忙到买不上，甜点由两个人轮流带，E1 就是桑多涅带的。这条线本身就是关系推进，不用额外写。主题轴：**深冬 → 春**，热的、能久放的、深夜买得到的 |

## 6. 三条必须守住的纪律（这个板块特有）

1. **没有图可看时，类比是唯一的桥。**E2 / E4 / E15 / E19 四座大山，每座都要一个
   全新的日常类比，且不能用 IT 比喻解释 IT。前三季已用的类比见手册 §3.3 与各季实录，
   别重复。
2. **诚实地不讲完。**手册原话：宁可讲透一半知识点也不要蜻蜓点水地全提一遍，
   **但要在结尾诚实地说「还有几个点这集没展开」**。这季正好把它写成仁菜的成长线——
   她从「假装听懂」到「说得出自己卡在哪」。
3. **每个数字都要给出处和前提。**这个板块全是显存、吞吐、精度损失、价格。
   裸报数字是本项目一贯的雷（S3E1 已立规矩：数字要连着场景一起报）。
