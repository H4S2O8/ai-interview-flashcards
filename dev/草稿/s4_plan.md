## 0. 一句话定位

> **S1 学会答，S2 练到过，S3 逼到做，S4 顶住量，S5 学会不做。**

deck `llm`，22 题，原文约十二万字，**全项目最难的板块**。
仁菜转正后接了 P0：一个日均两万一千次请求、双峰、P99 一秒二的推理服务。
这一季的课题是**顶住量** —— 每一个技术决定背后都有一笔要付的账。

## 1. 两个人（S4 版）

**这一季最重要的结构变化：桑多涅第一次有求于人。**

她手上有个卡了很久的问题，缺的是一份真实生产环境的负载分布 —— 那种数据
买不到、论文里没有、实验室造不出来。仁菜的 P0 正好有。所以这一季表面上
还是仁菜交学费，实际上是等价交换，而且是桑多涅先开的口。

这件事**不要在开头挑明，也不要每集提**。E1 她只说一句「这季……我有事求你」，
然后整季用行动体现（她会追问具体数字、会记下来、会因为某个数字改变判断），
终集才揭开：她那个卡了很久的问题，靠的就是 E1 仁菜随口报的那两万一千次、
双峰、P99 一秒二。

**关系刻度**：S1–S3 是老师和学生，S4 是这层关系第一次被打破。到 S5 才完全对等。
所以 S4 的落点不是「她终于对你好」，是**「她需要你，而且她说出来了」**。

**仁菜的成长线**：这一季她学会的不是某个技术，是**说「我不知道」**。
llm 板块全是「工程上真、学术上存疑」的东西，桑多涅全季反复说「这个不能说死」。
E7（Scaling Law / 涌现）是这条线的起点 —— 她第一次卡住，说
「我知道你每个字都是中文，但这一段我组不起来」。终集收口在：
**说不出边界的那部分，就是你还没懂的部分。**

**甜点整季去掉。** 五季七十七样已经腻，而且早就名不副实 —— 这一季真正的
筹码是数据，不是点心。去掉之后桑多涅的动机反而更清楚。

## 2. 每一集怎么写

**S4 的仁菜是真不会，不是装的。** 这一点和 S5 相反，必须守住 —— llm 板块
全是新理论，她第一次听 Transformer、RoPE、MoE，答错是真答错，要写成「够不着」
（「呃……」「我改口说……」），不是复述原文里的稻草人。到 S5 她已经有一年经验，
才有资格故意犯傻，「故意犯傻」这个默契也是在 S5 第一集才被点破的。**别提前用。**

**写作四条硬规矩见 `s5_plan.md` §2，两季共用**：一轮只讲一个意思靠换说法说透、
两个人要真的在听对方说话、仁菜是故意犯傻不是真傻、省略号与情感标记的用法。
这里只写 llm 板块特有的。

### 2.1 四座类比大山，不要赶

E2（Transformer）、E4（位置编码）、E15（量化）、E19（MoE）**没有公式可念、
没有图可看**，完全靠类比撑。这是全项目最吃写作能力的地方。

一座山一集，**每集只立一个中心比喻**，然后让它管到底。反面教材是 S5 第一版
那个「车间递纸条」—— 六十字铺陈、比它解释的东西还复杂。好比喻的标准是
S1 的心算与笔算：一句话说完，而且能点破本质（「不是你突然变聪明了，
是写下来的过程本身让你没法跳步」）。

### 2.2 原文最长的几集，宁可讲透一半

E10、E19、E20、E14 原文都在 7200 字以上。**宁可讲透一半知识点，
也不要蜻蜓点水地全提一遍** —— 但要在结尾诚实地说「还有几个点今天没展开」，
不要假装讲完了。

### 2.3 数字必须连着场景报

这一季全是数字：显存、参数量、Token 单价、延迟、吞吐。
**孤零零报一个数等于没报。** 每个数字后面跟一句它意味着什么 ——
「七百四十亿参数」要跟「按 FP16 装载就是一百四十八 GB，四张 A100 才放得下」。
台词里数字一律中文，别出现半角阿拉伯数字（GPT-4 这类带字母的除外）。

### 2.4 「这个不能说死」要说很多次，但每次说法不同

llm 板块深到一句话说死一定是错的：GPT-4 的参数量、涌现是不是测量假象、
DPO 等不等价于 PPO、外推是不是无损、量化的平均损失、各家 API 的默认值。
**这是这一季的暗线，也是仁菜成长线的养料**，但别每次都用同一句。

## 3. 开场与收尾（照 S1，不是照 S2–S3）

「欢迎回来」「进度」「预算还剩多少」「学费」「这算数据」「明天讲 X + 甜点名」
——**全部作废**。第一版里「这算数据」出现在 18/22 集的同一个位置。

**开场三轮以内**：
```
仁菜：《Agent 面试课》第四季第 N 集，我是仁菜。今天这道题是：<题目>。
桑多涅：<接的是人或她带来的问题，不是题>
仁菜：<她今天在 P0 上撞到的那件事，今天的题从这儿长出来>
```

**收尾**：桑多涅留一句私话，仁菜报下集主题并签退。

**每集必有一句「那这一集的雷是什么，你自己说」**，由仁菜复述要点。

**数据交换不做成仪式**：它是剧情线不是格式。有的集桑多涅中途就打断问数字，
有的集她听完不作声、下一集才提，有的集根本没发生 —— 然后她会说一句
「你今天没给我数」。

## 6. 这一季的知识主线（别让二十二集散成二十二篇文档）

一条线：**从「它为什么能说话」走到「它凭什么值这个钱」。**

E1–E5 是它长什么样（结构、注意力、位置、分词）→
E6–E11 是它怎么变成你要的样子（训练、微调、对齐）→
E12–E13 是它怎么开口（解码、参数）→
E14–E15、E19 是它怎么变便宜（缓存、量化、稀疏）→
E16–E18 是它怎么骗你（Prompt、CoT、幻觉）→
E20–E22 是它怎么上线、怎么证明、怎么选。

每一段都要有一笔账。这一季所有技术决定，最后都落在「这个决定花了多少钱、
省了多少钱、赌了什么」上 —— 这是它和 S1（讲原理）最大的区别。

## 7. 交接清单

   `(role, 显示文本, 合成文本)`，第三个才带 `[emotion]` 标记

7. **验证** `python dev/verify_audio.py --deck llm`
8. **发布** `dev/upload_r2.sh` → 逐集核公网 → `dev/publish_to_master.sh llm`
