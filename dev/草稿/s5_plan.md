## 0. 一句话定位

> **S1 学会「答」，S2 练到「过」，S3 逼到「做」，S4 撞上「不会」，S5 学会「不重造」。**

S4 终集桑多涅撂下：「别人的轮子怎么用。你写了四个月的东西，有一半已经有人封装好了。」
S5 就是这句话的兑现。

前四季仁菜一路在**往下挖**——从会答到会做到懂原理。S5 第一次要求她**往上抬**：
承认别人做得更好、学会读别人的设计、并且分得清「这个轮子该用」和「这个轮子不该用」。

- **deck**：`langchain`（articles.json `decks.langchain`，12 题，原文共 66986 字）
- **预估成稿**：按 S4 实测口径（知识压缩比 1.6x–3.3x）推，约 30k–38k 字 / 90–110 分钟。
  S4 预估偏低两成，这次按上限留量。
- **桑多涅身份**：沿用 S4 的「资深大模型工程研究员」，不需要改 `GUEST_ROLE_BY_DECK`。

## 1. 剧情线四件套（S5 版）

| 线 | S5 设计 |
| --- | --- |
| **阶段性目标** | **交付倒排**。S1 倒计时、S3 里程碑、S4 预算，这季用**工期**：公司要在若干周内交付一个对外的 Agent 产品，而仁菜手上是四个月攒下的一堆自研零件。每集台词里出现一次「还剩几周」。这条线天然逼出本季的核心冲突 —— 自研的舍不得丢，但工期不等人 |
| **桑多涅的动机** | S4 她有求于人（要生产负载数据），这季**反过来**：她要仁菜帮她做一件她做不了的事 —— 她只做研究不做交付，没有真实工期压力下的取舍样本。所以这季她**跟着学**，学的是「什么时候该放弃更优解」 |
| **仁菜的成长** | 老毛病「看到更强的就想上」在这季变形成**「这个我自己能写」**——舍不得丢自研零件。E2、E5、E9 三次变体。**新课题是「分得清该不该造」**：终集她给出的不是「全用框架」也不是「全自研」，是一条能说清边界的分界线 |
| **甜点账本** | S4 是「两人轮流带」，这季**再变一次：仁菜没时间买了**。前段是便利店和外卖，中段桑多涅开始带，后段两人一起在楼下摊子上吃。主题轴：**夏，糖水与冰品**（S3 秋、S4 冬春，季节接得上） |

## 3. 关系线（S5 **不设**「软化点」）

> 「软化点全季仅三次」是 S1/S2 的纪律 —— 那时桑多涅还是个陌生的出题人，
> 每次解冻都是事件，必须省着用。到 S5 这条纪律已经过期：S4 结尾她自己说过
> 「收情报是双向的，我从来没占过你便宜」「这四个月你没有一次说差不多就行」。
> 再把「她带了甜点」「她熬夜没走」当稀有时刻来铺垫和收束，等于把关系倒退两季。

**S5 的默认底色就是同行。** 带甜点、熬夜在场、直接说「这个结构比你十二天前
想的那个好」，都是常态，不需要理由，也不许被写成奖赏。

这一季要推进的不是亲密度，是**对等**。三个刻度：

- **E5**：她删掉自己写的一百三十行，桑多涅只回「……删得对」。
  这不是软化，是**第一次以判断回应判断** —— 前四季都是她判、仁菜听
- **E10**：桑多涅熬夜在场，理由是自私的 —— 她做研究不做交付，
  拿不到「工期里亲手删掉自研」这个样本。**不许写成关心**。
  收在「我以为我要记的是你怎么放弃 —— 你没放弃，你只是终于分得清哪部分值得留」
- **E12**：她问「下一季你想讲什么」。前四季都是她定题，**把选择权交出去**
  才是这季真正的终点

**写作纪律（从 S1 起没变，变的只是她出现的频率）**：桑多涅不说「我担心你」
「早点休息」这类句子。她的关心一律走事务性外壳 ——「碗我带回去」「你明天还要
上班」「凉了才好喝」。判断句可以直给，情绪句一律不给。

## 4. 经验题的态度变体（这个板块的「别装」）

langchain 板块没有像前几季那样成组的经验题，但有三处必须用同样的态度打：

- **E1**（框架盘点）：「说你了解哪些框架，不是让你背名字。说你**放弃过**哪个，为什么」
- **E7**（LangChain vs LlamaIndex）：「这两个不是竞品。答成竞品，说明你两个都没真用过」
- **E12**（Deep Research）：「这个词现在很热。热词最容易考出真假 —— 你说得出它**不适合**什么场景吗」

## 6. 这个板块特有的三条纪律

1. **不许念 API。**遇到类名、方法名、包名，一律讲它解决什么问题。
   判据：把讲稿里所有专有名词遮掉，剩下的话还能不能说清这一集在讲什么。
2. **重叠集必须写明分工。**这个板块和前四季重叠最多（E4 对 S1、E5 对 S2、E6 对 S3），
   每一处都要让桑多涅显式说出「那集讲 X，这集讲 Y」—— S4E18 对 rag 板块用过这个手法，有效。
3. **时效内容要写成判据，不要写成快照。**E11 尤其。版本号会过期，
   「怎么判断该不该升」不会。

   `✗` 必须改到过；`!`（压缩比上限警告）要人工核原文覆盖 —— S4 里四次触发两次是真漏
5. **节奏**：写完跑 `python dev/rhythm.py dev/草稿/s5_eps.py N` 补破折号节奏。
   它不会改坏文本，但只补节奏、不补感叹号和问号，那两项写的时候自己带够
6. **验证**：探针全绿 → `--deck langchain --dry-run` → 合成
7. **发布**：`dev/verify_audio.py --deck langchain --remote` → `dev/upload_r2.sh` →
   `dev/publish_to_master.sh langchain`
