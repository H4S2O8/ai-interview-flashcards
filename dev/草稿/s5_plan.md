## 0. 一句话定位

> **S1 学会答，S2 练到过，S3 逼到做，S4 顶住量，S5 学会不做。**

deck `langchain`，12 题。仁菜的公司要在几周内交付一个对外的 Agent 产品，
而她手上是四个月攒下来的一堆自研零件。这一季的课题不是学会造更多东西，
是**分得清什么不用自己造**。

## 1. 两个人（S5 版）

**桑多涅这一季有自己的目的，而且是自私的。** 她做研究不做交付，拿不到
「一个人在工期底下亲手删掉自己写了十二天的东西」这种样本。她来是为了收这个。
两个人都知道，谁都不说破成关心。

这条线取代了前四季的「甜点报酬」。**甜点这一季整个去掉** —— 五季七十七样，
已经腻了，而且早就名不副实：S4 的筹码已经换成情报，S5 换成样本，甜点只剩空壳。
去掉之后她的在场理由反而更硬。

**仁菜的老毛病换了战场**：以前是「看到更强的就想上」，这季是**「这个我自己能写」**。
三次变体：E2 看过源码觉得自己能写、E5 舍不得那个工具注册层、E9 花十二天把
已经在图上跑的东西又搬到图上跑了一遍。

**关系推进的不是亲密度，是对等。** 三个刻度：

- **E5**：她删掉自己写的一百三十行，桑多涅只回「删得对」—— 第一次以判断回应判断
- **E10**：桑多涅熬夜在场，理由是自私的（她要那个样本），**不许写成关心**
- **E12**：她问「下一季你想讲什么」。前四季都是她定题，把选择权交出去才是终点

**写作纪律**：桑多涅不说「我担心你」「早点休息」。她的关心走事务性外壳 ——
「查完给我发一句」「我明天想知道」。判断句直给，情绪句不给。

## 2. 每一集怎么写（这一季最要紧的部分）

前一版十二集全部返工，问题不在知识点，在对白本身。四条硬规矩：

### 2.1 一轮只讲一个意思，靠换说法说透

这是「AI 味」的真正来源。反面和正面：

- **密（错）**：「三样：名称、描述、参数 Schema。而且它们是分两次被用到的 ——
  它先扫名称和描述……所以前两样决定它选不选得对，Schema 决定它填不填得出
  能用的东西。写砸了症状完全不一样。」→ 四个新信息连着来，没地方喘气
- **碎（也错）**：把上面拆成一人一句的快问快答 → 变成讲课带个人偶
- **对**：「就三样：名称、描述、参数 Schema。你可能觉得这三样是一块儿交给模型的，
  其实不是，它读这三样是分两次的。第一次它只看名称和描述，那会儿它还没决定
  用不用你这个工具，它在挑；等它挑中了，才回过头看 Schema，那会儿它在填。
  所以这三样管的是两件事 —— 名称和描述决定它挑不挑得对，Schema 决定它填不填得进去。」

一个概念，说三遍，换三种说法。**长轮不是问题，一轮塞四个新概念才是问题。**

参照：S1 桑多涅平均 60.7 字/轮，全季 61 轮/集。不要靠拆轮次降密度。

### 2.2 两个人要真的在听对方说话

反面（第一版里的）：桑多涅问「为什么是九块」，仁菜答了一句有分量的话，
桑多涅一个字不接，直接「那今天讲工具怎么注册」—— 那句问话不是关心，
是拿来递台词的开关。

正面（S1E05）：

```
仁菜：等一下 —— 这个循环，是模型自己在循环吗？
桑多涅：……你居然主动问到了这个。
仁菜：因为上一集你说过「模型只负责决策」，我就想这里是不是也一样。
桑多涅：是一样。这是这题最常踩的误区：……
```

**先听见对方，再回答。** 桑多涅还要会因为听到的事情改主意 ——
E5 里她听说 user_id 是模型填的，当场把今天的重点换成「回去查日志」。

### 2.3 仁菜是故意犯傻，不是真傻

第五季的人还什么都不懂，人物就垮了。所以把犯傻立成两人的默契，
并且**在全季第一集就点破**：

```
桑多涅：……你刚才那句是故意的。
仁菜：……嘿嘿。因为你拆一遍我才记得住嘛。你直接讲我听完当天就忘；
      你把我打一顿，我一辈子记得那个坑长什么样。
```

立住之后两种错就分得开：**装傻**（复述原文里的错误答案）一句「嘿嘿」带过；
**真栽**（她自己的设计错误）她明说「这次不是故意的」。后者才配得上数据。

### 2.4 省略号与情感标记

「……」对 Fish Audio **完全无效**（带与不带同长），它只影响字幕。
**整轮只有「……」会合成出数秒有声乱码**（桑多涅 4.88s、仁菜 2.04s，
峰值 7000–10000 从头响到尾，单测抽到过 47.55s）。

- 省略号控制在 **8% 左右的轮次**（S1 是 8%，第一版是 38%）
- 要沉默一拍：字幕仍写「……」，**合成文本走 `[sighing]`**（`T` 的第三参）
- 情绪一律交给标记，别靠标点堆：`[uncertain]` `[embarrassed]` `[disappointed]`
  `[excited]` `[nervous]` `[upset]` `[shouting]` 等，实测被解析且不会念出来
- `[break]` / `[long-break]` 测不出停顿，**不要用**

## 3. 开场与收尾的固定结构（照 S1，不是照 S2–S4）

前四季堆起来的仪式 —— 「欢迎回来」「进度」「还剩 X 周」「学费」「这算数据」
「明天讲 X + 甜点名」—— **这一季全部不用**。S1 里「欢迎回来」出现 0/16 次。

**开场三轮以内**：
```
仁菜：《Agent 面试课》第五季第 N 集，我是仁菜。今天这道题是：<题目>。
桑多涅：<接的是人，不是题 —— 如「……你眼睛。」>
仁菜：<她自己带来的问题，今天的题从这儿长出来>
```

**收尾**：桑多涅留一句私话（可以是要求、判断、或者事务性的关心），
仁菜报下集主题并签退。不要让两个人都报一遍下集。

**每集必有一句「那这一集的雷是什么，你自己说」** —— 由仁菜自己复述要点，
代替原来的「学费 + 这算数据」。

## 6. 这一季的知识主线（别让十二集散成十二篇文档）

一条线串下来：**你写的东西和框架已经写好的东西，边界在哪。**

E1 建立「框架解决的是第十几步还能恢复、出错还能定位」→
E2–E4 是框架替你做的（组合协议、分层、七步）→
E5–E6 是框架管不到、必须你自己管的（可信参数、作用域）→
E7–E8 是别的框架怎么切这条边界 →
E9–E10 是同一套东西的两层，你控制哪一层 →
E11 是这条边界会随版本移动 →
E12 收口成一句她自己的判据：**这段东西出错的时候，是谁去道歉。**

## 7. 交接清单

1. **工作区** `~/Projects/flashcards-dev`（dev worktree）
2. **起草** `dev/草稿/s5_eps.py`。每轮写 `(role, 显示文本)` 或
   `(role, 显示文本, 合成文本)`，第三个才带 `[emotion]` 标记
3. **注入** `python dev/inject_deck.py dev/草稿/s5_eps.py langchain "S5：..."`
4. **体检** `--dry-run`（会拦整轮省略号没给合成文本的情况）
5. **过闸** `python dev/check_script.py <讲稿.txt> --deck langchain --qno N`
6. **合成** `--deck langchain`。**改过稿的集数必须先删 mp3 和 lrc，或者加 `--force`**，
   否则会被 `skip（已存在）` 静默跳过，留下旧音频配新字幕
7. **验证** `python dev/verify_audio.py --deck langchain`
8. **发布** `dev/upload_r2.sh` → 逐集核公网 → `dev/publish_to_master.sh lc`

## 8. 阈值都要按上线季实测定，不要拍脑袋

这一季我在闸门里拍错过**四条**阈值，每条都和上线季矛盾，而且每条都让稿子更差：

| 规则 | 我拍的 | 上线季实测 |
| --- | --- | --- |
| 桑多涅单轮上限 | 110 字（注释写「她说话短」） | S1 最长 191、S2 最长 318 |
| 压缩比下限（轮级） | 1.6x | tools 最低 1.34x，且轮级口径依赖分轮方式 |
| 桑多涅均轮长下限 | 40 字 | rag 第 2 集只有 29.3 |
| 人味带 | 语气词轮 51–93%、感叹号 3–15 | **S1 是 18–43% 和 0–3** —— 这条会把 S1 判为没人味 |

最后一条尤其要记：那条带恰好等于「除 S1 外的所有季」，等于逼着每一季都写成
S2 的外放腔调，而 S1 才是最自然的一季。

## 9. 第一版为什么返工（供后来者避坑）

第一版十二集全部过闸、合成、上线，然后被逐条推翻：

1. **对白被绞碎** —— 桑多涅均 25.3 字（上线季 49–86），因为我照着自己拍的
   110 字上限拆讲解
2. **AI 味** —— 一轮塞四个新概念，两个人不听对方说话，仁菜退化成提问机
3. **仪式脚手架** —— 每集开场六轮：欢迎回来 + 甜点 + 进度 + 还剩 X 周 + 报题；
   结尾五轮：学费 + 这算数据 + 明天讲 X + 甜点名。十二集一模一样
4. **软化点写法过期** —— 第五季还把「她带了甜点」当稀有时刻，倒退两季
5. **省略号 38%** —— 是 S1 的近五倍，而它对 TTS 根本无效；
   还留下 10 处整轮省略号，合成出数秒有声乱码
6. **甜点腻了** —— 五季七十七样，而且早已名不副实

中间还走过一次弯路：为了降密度把对白切成 216 轮一人一句，桑多涅均字掉到 18.8，
等于绕回第 1 条。**降密度靠的是一轮讲一个意思，不是拆轮次。**
